## 💡 Dicas de Nomenclatura para o Git

Para facilitar a organização e leitura no repositório GitHub, sugerimos o padrão:
```
[ANO]_[NOME-DO-CURSO]_[INSTITUICAO].pdf
```
Exemplos:
* `2026_AWS_Solutions_Architect_Amazon.pdf`
* `2026_Python_Data_Engineer_Coursera.pdf`
* `2026_Scrum_Master_PSM_ScrumOrg.pdf`

---

## 🤝 Sincronização com o Repositório Git
Ao adicionar arquivos nesta pasta e enviar para o GitHub:
```bash
git add meus-certificados/
git commit -m "feat: adiciona certificados em meus-certificados"
git push
```
Qualquer pessoa que clonar o seu repositório terá acesso direto a todos os seus certificados!
